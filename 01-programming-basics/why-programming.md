# Why Programming?

## WHY?
People invented programming to make machines perform useful work reliably and repeatedly. A program lets a person describe a process once instead of manually directing every small machine operation.

## WHAT?
Programming is the act of expressing a solution as precise instructions and data that a computer system can carry out. It includes understanding the problem, designing an algorithm, writing code, testing it, and maintaining it.

## HOW?
A programmer breaks a task into steps, conditions, repetition, and reusable operations. A language implementation translates those statements into operations the computer's hardware and runtime can execute. The computer follows those rules; it does not infer the programmer's unstated intentions.

## WHERE?
Programs run on phones, personal computers, browsers, servers, embedded controllers, and large distributed systems. Code may run locally, in a data center, or across several of these places.

## WHEN?
Programming is useful when a task can be described clearly and automation, repeatability, speed, or scale is valuable. For a one-off task, a manual process or an existing tool may be simpler.

## WHO?
People with knowledge of a problem define what should happen; programmers turn that understanding into instructions. Compilers, interpreters, operating systems, and processors carry out different parts of execution, while users experience the result.

## WHAT IF?
If instructions are incomplete or wrong, the computer still follows the written rules, which can produce bugs or unsafe outcomes. Testing, reviews, monitoring, and clear requirements help catch the gap between what people meant and what the program says.
